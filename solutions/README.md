# Solutions

A complete answer for every lesson. Try the exercise yourself first. SQL often has several correct answers (a join or a subquery, `IN` or `OR`), so if yours passes the tests, it's right, even if it looks different from these.

To check a solution, copy it into the lesson folder as `exercise.sql` (keep a copy of yours first), then run `python3 -m unittest -v` there. To just see what it returns, run it from this folder: `python3 ../run.py 07-joins.sql`. Use `--empty` for lesson 9.
